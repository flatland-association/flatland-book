ECML 2026
=========

The **[ECML 2026 Challenge](https://competition.flatland.cloud/suites/6240c685-0fb4-481e-9404-47a570632227)** is the newest competition around the Flatland
environment.

- Read about the [level configurations](ecml2026/levelconfig) of this edition.

🗺️ Topology
----------
The competition runs on a single topology (120 x 150) with 28 stations:

![competition_map.png](../assets/images/ecml2026_competition_map.png)

The map is subdivided into five *scenes* (i.e. regions):

![competition_scenes.png](../assets/images/ecml2026_competition_scenes.png)

The scenes correspond to the scenarios in each level with the exception of level 6, where all five scenarios use scene 5 (
cf. [level configurations](ecml2026/levelconfig)).

Competition features:

- Intermediate stops: the lines have **intermediate** stops. The environment does not enforce agents to pass by intermediate stops, but agents (trains) are
  penalized
  if they skip intermediate stops are do not respect time windows defined for intermediate stops, see [ECML 2026 Evaluation Metrics](ecml2026/eval.md).
  Intermediate stops are defined by a set of alternative grid cells in the same station.
- Speeds: the agents always run at their train category's `max_speed<=1.0` or at zero, we do not use variable speed in the competition (i.e.
  `acceleration_delta=1.0` and `braking_delta=-1.0` see [Actions](../environment/actions))

⭐ Supported Flatland Versions
-----------------------------
You must use Flatland version [4.2.5](https://github.com/flatland-association/flatland-rl/releases/tag/v4.2.5)
or [4.2.6](https://github.com/flatland-association/flatland-rl/releases/tag/v4.2.6).
