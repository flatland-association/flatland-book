# Community Projects

Community projects are initiatives driven by members of the Flatland community, e.g. new research directions, tools, scenarios or
extensions of the Flatland framework. Each project has its own page describing its goal, its approach, how the collaborators work
together and who is involved.

## Projects

| Project                                            | Goal                                            | Status     | Tag                       |
| -------------------------------------------------- | ----------------------------------------------- | ---------- | ------------------------- |
| [Project Template](community-projects/template.md) | _Template to copy when proposing a new project_ | _template_ | _`project:<short-name>`_ |

Each project has a **tag**. Issues and pull requests belonging to a project carry its tag (as a GitHub label, or in the title),
so that work on a project can be found across all Flatland repositories.

## Propose a Project

Do you have an idea for a project? Write it down and share it with the community:

1. Get the [`flatland-book` repository](https://github.com/flatland-association/flatland-book):
    - if you are a collaborator of the repository, clone it and create a branch, e.g. `community-project/<your-project>`;
    - otherwise, fork it and clone your fork.
2. Copy [`resources/community-projects/template.md`](https://github.com/flatland-association/flatland-book/blob/main/resources/community-projects/template.md)
   to `resources/community-projects/<your-project>.md` and fill in
    - **title**,
    - **goal**,
    - **description**,
    - **collaboration procedure** (meetings, communication channels, ...),
    - **collaborators**, and
    - the summary at the top with **status**, **contact** and **tag**.
3. Add your page to `_toc.yml` in the sections below `resources/community-projects`.
4. Add a row for your project to the table above.
5. Open a pull request.

See also the [contribution guidelines](../misc/contributing.md) for how to contribute to the Flatland book.
